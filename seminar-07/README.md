# Паттерны устойчивости

[Слайды семинара (PDF)](slides/dist/S7_Resilience.pdf)

Нужен Python 3.8 или новее. Откройте терминал в папке с `lab.py`. Каждый опыт поднимает HTTP-сервис на свободном порту `127.0.0.1` и останавливает его при выходе. Установка пакетов и Docker не нужны.

## Лимит одновременных запросов

```sh
python3 lab.py admission --limit 2
python3 lab.py admission --limit 4
```

Шесть клиентов вызывают один обработчик. Принятые запросы занимают места, пока сервер не проверит всю шестёрку. Сравните решения сервера в строке `gate` с ответами, полученными клиентами в строке `batch`. Отдельный `next_request` приходит после завершения всей пачки.

Найдите минимальный лимит, при котором хотя бы три запроса получают 200. Сравните свой результат с соседним меньшим значением. В `Service.limited_work` найдите, где семафор занимает место, где сервер выбирает 503 и где место освобождается.

## Повторы

```sh
python3 lab.py retries
```

Четыре запроса читают рекомендации и цену. Сервис рекомендаций отвечает 503, цена доступна. Сравните число обращений к серверу в строках `total`.

| Политика | Что должно получиться |
|---|---|
| `two_layers` | По три попытки в каждом из двух слоёв. До сервера доходят 28 вызовов |
| `one_layer` | Повторяет только один слой. До сервера доходят 10 вызовов |
| `budget` | На всю серию выделено два дополнительных вызова. До сервера доходят 6 вызовов |

Во всех трёх случаях выполнен один пользовательский запрос. Подберите максимальный бюджет, при котором сервер получит не более пяти обращений на четыре исходных запроса. Начните с нуля и меняйте число после `--budget`. Сравнивайте `backend_calls` и `ok` в итоговой строке режима `budget`.

```sh
python3 lab.py retries --budget 0
```

## Изоляция зависимостей

```sh
python3 lab.py isolation
```

Два медленных запроса претендуют на два места. В режиме `shared` цена получает `pool_full`, и счётчик обращений за ценой равен нулю. В режиме `split` одно место зарезервировано для цены. Она возвращает 200, пока медленный запрос ещё выполняется.

В строках `breaker` проследите за `backend_calls`. На третьем шаге зависимость уже исправна, но счётчик остаётся равен двум. Первая разрешённая проба проходит на четвёртом шаге. `basic` означает карточку без рекомендаций, `personalized` — карточку с ними.

Теперь восстановите зависимость после первой ошибки. Какими станут `via` и `backend_calls` на третьем шаге? Проверьте, был ли среди пяти вызовов хотя бы один `probe`.

```sh
python3 lab.py isolation --recover-after 1
```

Опыты можно повторять в любом порядке. Флаг `--fast` пропускает паузы для чтения вывода. Пауза открытого выключателя сохраняется. На Windows те же команды можно вызвать через `py -3` вместо `python3`.
