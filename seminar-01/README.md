# С1. Мониторинг высоконагруженных систем

Стенд: API, Prometheus, Grafana и k6. Эксперименты показывают, как задержки, очередь и ошибки отражаются в метриках.

## С чего начать

1. [Подготовить и запустить стенд](docs/01_from_zero.md).
2. [Выполнить эксперименты и сохранить результаты](docs/02_experiments.md).
3. [Разобраться в коде и командах](docs/03_under_the_hood.md).
4. [Найти причину ошибки](docs/06_troubleshooting.md).

[Презентация](dist/S1_Monitoring.pdf). Запросы PromQL находятся в `lab/prometheus/queries.json`.

## Что понадобится

Bash, OpenSSH, Python 3 и Yandex Cloud CLI. Для облачного запуска нужен доступ к каталогу с разрешением создавать ресурсы. Конфигурация ВМ: 4 vCPU, 8 GB RAM, 30 GB SSD. Ресурсы платные; проверьте стоимость перед созданием. Локальный запуск с Docker Compose описан в конце `01_from_zero.md`.

На macOS команды выполняются в Bash; на Windows — в WSL2.

## Каталоги и настройки

- `cloud/` — создание ВМ, SSH-подключение и удаление ресурсов.
- `lab/` — приложение, мониторинг, нагрузка и тесты.
- `docs/` — инструкции.
- `dist/` — презентация в PDF.

`cloud/env.example` копируется в `cloud/env.local` на ноутбуке; `lab/env.example` — в `lab/.env` на ВМ. Подготовка обоих файлов описана в `01_from_zero.md`. Пароли, ключи и файлы с реальными настройками не публикуйте.

Нагрузку запускайте на своём стенде. Проверяйте `dropped_iterations`: если генератор пропускает запросы, низкая задержка не доказывает запас мощности приложения.
