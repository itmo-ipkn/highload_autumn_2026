# HOMEWORK 1. Инструменты автоматизации в Grafana

CRUD-сервис на `Python` с метриками золотых сигналов (`rps`, `latency`, `errors`), динамический генератор дашбордов `Grafana` по динамическому списку эндпойнтов сервиса и фоновая нагрузка на `Locust`.

cd homework_1
```

make cp_env
```
```bash

```

```bash
docker compose down -v
```

## Описание

CRUD-сервис развернут на двух stateless-экземплярах FastAPI с проксированием и балансировкой запросов через `nginx`. Состояние БД сохраняется между запусками приложения (если сервис был остановлен без удаления `volumes`). Нагрузочный тест запускается автоматически после старта основных сервисов и останавливается либо через 100 минут, либо при остановке сервиса. В браузере доступны `Prometheus (http://localhost:9090)`, `Grafana (http://localhost:3000)`, `Locust (http://localhost:8089)`. Пользователи и пароли указаны в файлах переменных окружения.

### Endpoints

| Method | Endpoint | Status codes |
| :--- | :--- | :--- |
| POST | /items | 200, 422 (невалидное тело запроса) |
| GET | /items/{id} | 200, 404 |
| PUT | /items/{id} | 200, 404, 422 (невалидное тело запроса) |
| GET | /health | 200, состояние сервиса |
| GET | /metrics | 200, метрики Prometheus |
| GET | /handlers | 200, динамический список эндпойнтов за исключением служебных |

### Storage

`Redis + RDB + AOF` для персистентности (сохраняется состояние между запусками). Доступ в хранилище по паролю (использованы docker secrets).

### Metrics and labels

**Metrics:** `http_requests_total`, `http_request_duration_seconds`, `http_errors_4xx_total`, `http_errors_5xx_total`

**Labels**: `DATACENTER`, `POD_ID`, `METHOD`, `ENDPOINT`, `STATUS_CODE`

Причина выбора гистограммы как типа метрики - внутри они представляют собой счетчики, соответствующие диапазонам значений, из-за чего могут быть просуммированы по разным источникам (датацентрам, подам), а уже на основе просуммированных бакетов будет строиться конечная гистограмма.

### Дашборд-генератор

Запускается автоматически после успешного старта `nginx` и `grafana`, забирает актуальный список эндпойнтов, генерирует дашборды и создает их в графана.
Дашборд создается без возможности его редактирования, в целях упрощения демонстрации доступ в графану осуществляется с учетными данными админа.

### Нагрузка

`Locust`, автостарт при запуске приложения, запросы отправляются на балансировщик.

`POST`, `GET`, `PUT` запросы на существующие эндпойнты с валидным и не валидным телом запроса (3% ошибок - 422 статус).

`POST` запросы с валидным телом на несуществующий эндпойнт (3% ошибок - 404 статус).

`GET`, `PUT` запросы на существующие эндпойнты с заведомо несуществующим ID (3% ошибок - 404 статус).

Суммарно выходит около 10 % ошибок трёх кодов от инструмента нагрузочного тестирования.

Приложение `FastAPI` поддерживает режим выброса случайных ошибок (по умолчанию 2% запросов - 500 статус), реализованный через middleware. Режим включается и настраивается через переменные окружения.

### Секреты

Логины и пароли для доступа к `Redis`, Prometheus добавлены через монтирование файла с помощью `secrets`. В остальных случаях чувстввительная информация добавляются через переменные окружения, сами файлы `.env` добавлены в `.gitignore` и `.dockerignore`. Образцы заполнения файлов доступны в соответствующих `.env.example`-файлах.

В демонстрационных целях используются значения переменных из `.env.example`-файлов.
