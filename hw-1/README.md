# Каталог товаров — первый этап ДЗ №1

TypeScript + Fastify, один процесс, независимое хранилище в памяти. После перезапуска все товары теряются. Этот этап содержит только API и контейнерный запуск.

## Docker Compose

Из каталога `hw-1/`, при запущенном Docker Desktop / Docker Engine:

```bash
cp .env.example .env
docker compose up
```

Node.js на хосте не требуется. Первый запуск собирает образ и загружает зависимости. API: http://127.0.0.1:8080, готовность: http://127.0.0.1:8080/health. Порт можно изменить через `API_PORT` в `.env`; внутри контейнера используется 3000. `.env` не хранится в git, секреты на этом этапе не требуются.

```bash
docker compose ps
docker compose down
# После изменения исходников:
docker compose up --build
```

## API

Товар: `{ "id": "UUID", "name": "Клавиатура", "price": 450000 }`. Цена — целое число копеек (450000 = 4500 ₽), от 0 до 9007199254740991. Имя — 1–200 символов после trim. POST и PUT требуют оба поля name и price. Строковые числа, неизвестные поля и клиентский id отклоняются. PUT полностью заменяет name и price, не создавая отсутствующий товар.

| Запрос | Ответ |
|---|---|
| POST /items | 201, созданный товар |
| GET /items/{id} | 200, товар; 404, если отсутствует |
| PUT /items/{id} | 200, обновлённый товар; 404, если отсутствует |
| GET /health | 200, `{"status":"ok"}` |

Невалидное JSON-тело и нарушения схемы дают 400 без изменения хранилища. Ошибки содержат JSON-поле `message`. Неподдерживаемый Content-Type даёт 415.

```bash
curl -i -X POST http://127.0.0.1:8080/items \
  -H 'Content-Type: application/json' \
  -d '{"name":"Клавиатура","price":450000}'

# Подставьте id из ответа POST:
curl -i http://127.0.0.1:8080/items/ID
curl -i -X PUT http://127.0.0.1:8080/items/ID \
  -H 'Content-Type: application/json' \
  -d '{"name":"Мышь","price":150000}'
curl -i http://127.0.0.1:8080/items/missing
```

## Разработка и тесты

Node.js 24.21.0 (`nvm use` при установленном nvm) и pnpm 10.19.0. Версия pnpm закреплена в `package.json` и Dockerfile. Если pnpm ещё не установлен: `npm install --global pnpm@10.19.0`. Docker устанавливает его самостоятельно. Из `hw-1/`:

```bash
pnpm install --frozen-lockfile
pnpm run build
pnpm test
pnpm start
```

Локальный процесс слушает порт 3000; переменная `PORT` переопределяет его. Остановка — Ctrl+C. Для перезапуска при изменении исходников:

```bash
pnpm run dev
```

HTTP-тесты используют Fastify inject без открытого порта. Проверяют CRUD, валидацию, границы цены/имени, отсутствие upsert, изоляцию и пустое хранилище нового приложения.

## Структура

- `src/app.ts` — сборка приложения, отдельный `/health`.
- `src/server.ts` — запуск и завершение процесса.
- `src/products.ts` — бизнес-ручки и схема запросов.
- `src/store.ts` — модель и Map-хранилище.
- `tests/` — HTTP-проверки.

Память растёт с числом созданных товаров; автоматического удаления нет. Длительную нагрузку и её ограничения добавим отдельным этапом.
