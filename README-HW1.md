1. Как запустить:

   - Для запуска можно либо создать файл .env в директории hw1 и вставить в него содержимое файла .env.example, 
   - либо воспользоваться конфигурационным скриптом configure.go, который лежит в директории scripts, по пути /hw1/scripts. Запустить скрипт можно командой `go run configure.go`
   - После создания .env, находясь в директории /hw1, запускаем команду docker compose up -d
   - После успешного запуска, можно открыть grafana, запущенную на порту 3000 и пользоваться дашбордом
2. Метрики и лейблы

    1.1 Метрики
    - http_server_requests_seconds_sum - суммарное время выполнения обработки запросов в секундах
    - http_server_requests_seconds_count - количество запросов в секунду
    - http_server_requests_seconds_bucket - гистограмма распределения времени выполнения запросов
    
    1.2 Лейблы
    - method - название HTTP-метода
    - uri - uri запроса
    - status - статус ответа
    - datacenter - наименование дата центра
    - pod_id - id пода
    - job - наименование задания сбора метрик
    - le - верхняя граница интервала гистограммы задержек
3. Расчеты Latency
    - Для расчета среднего latency были выбраны метрики http_server_requests_seconds_sum и http_server_requests_seconds_count, 
    т.к. можем взять среднее значение скорости обработки в секундах за определенный период времени и разделить на среднее значение количества запросов за этот период времени
    - Для расчета перцентилей использовалась метрика http_server_requests_seconds_bucket, т.к. содержит информацию о распределении времени ответа по интервалам. 
    - Вместе с этой метрикой также использовалась функция histogram_quantile, которая позволяет на основе данных предоставляемой этой метрикой расчитать перцентили
